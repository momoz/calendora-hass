# ACTION, and Home Assistant will not validate one without loading the
# mobile_app integration — which pulls in the voice/media stack behind it.
# Without these, device-action validation fails with "Integration 'mobile_app'
# does not support device automation actions", which reads like a Home Assistant
# limitation and is actually a missing import. That misleading message is the
# reason they are listed with a comment instead of discovered again later.
#
